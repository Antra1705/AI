test 12730 windows; the test runs also have 754 rumble-strip windows (a surface never seen in

## Uncertainty and safety fallback

A window is flagged *uncertain* when confidence < 0.824 or mutual information > 0.0533
(2.5th / 97.5th percentiles of correctly classified validation windows), or novelty
(squared Mahalanobis distance to the nearest class, one covariance per class) > 88.2 (99th percentile of validation).

| | Value |
|---|---|
| Test windows accepted (coverage) | 95.5% |
| Accuracy on accepted windows | 99.8% |
| Accuracy on flagged windows | 82.0% |
| Rumble-strip (unseen surface) windows flagged | 7.6% |
| Rumble-strip windows flagged by 1 model + confidence gate only | 6.8% |
| Ambiguous (transition) windows flagged | 49.3% |
| AUROC unseen-surface detection, ensemble mutual information | 0.823 |
| AUROC, ensemble 1 - confidence | 0.795 |

All numbers come from simulated data. Retrain on recordings from the real cart
(log raw -> replay --label -> this script) before trusting them.
