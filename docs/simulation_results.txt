1. Ride and damping
================================================================
Closed-loop ride comparison: 8 random tracks x 40 m (unseen in training), same cars,
same speed (PWM 200) for every strategy so only the damping differs. Lower is better
for every column except accuracy.

Strategy                             smooth   gravel     event   bottom     servo    pothole   class.
                                   RMS m/s2 RMS m/s2 peak m/s2 outs/evt     deg/m   react ms     acc.
Passive soft (servo fixed 45)         0.178    1.419     47.74     8.68       1.0          -        -
Passive stiff (servo fixed 150)       0.055    7.324     10.82     1.05       1.4          -        -
SRA: rules + fixed angles             0.070    5.177     31.82     2.79      80.4 343 (0 miss)    93.3%
Neural + fixed angles                 0.072    4.964     32.59     3.27      67.9 372 (13 miss)    97.5%
Neural + graded curve (deployed)      0.057    2.180     13.54     1.38      63.4 201 (0 miss)    98.6%

smooth/gravel RMS: body vertical acceleration away from events (comfort).
event peak: largest body acceleration within 1 s of a breaker/pothole (protection).
bottom outs/evt: suspension hitting its travel limit per breaker/pothole.
servo deg/m: total servo movement per metre driven (actuator wear).
pothole react: front wheel reaches the pothole -> servo physically at >= 140 deg
               (miss = not within 0.5 s).

Deployed classifier in closed loop: 98.6% correct, 4.3% of windows flagged uncertain.
